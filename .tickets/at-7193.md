# Access Crit reviews over permanent tailnet HTTPS

Deploy the hostname-based router behind Reef's managed Caddy with private wildcard DNS and a certificate for per-review names beneath crit.wharfi.sh. A browser on another tailnet-connected device must open the full CLI review UI without per-session SSH forwarding or localhost callbacks. Use a stable proxy configuration so adding/removing reviews does not require privileged Caddy reloads.

Keep the current Crit Web deployment and stored data intact during validation. Use a temporary validation entry hostname where necessary before the root-hostname cutover in the final ticket. Follow existing chezmoi, DNS administration, certificate, and service ownership conventions. Keep backend listeners on loopback and external proxy access tailnet-only. Prepare concrete configuration and rollback before any live deployment action, retaining applicable authorization boundaries.

No upstream code or release is required. This slice validates code/document reviews only; remote live app and HTML preview are excluded.

## Acceptance Criteria

- [ ] Private wildcard review names resolve correctly from a remote tailnet device and present valid HTTPS certificates.
- [ ] All backend listeners remain loopback-only; access does not require public DNS records, public listeners, Funnel, SSH tunnels, or laptop callbacks.
- [ ] A remote browser loads Git and document reviews, adds comments, receives streaming updates, finishes one review independently, and completes a revision round.
- [ ] Five concurrent remote review URLs remain correctly routed, including targeted daemon restart and browser reconnect.
- [ ] New reviews become reachable without per-review DNS edits or privileged Caddy reloads.
- [ ] Unrelated services and the existing Crit Web deployment remain available through validation; configuration rollback is documented and checked.
- [ ] Remote browser evidence distinguishes real human review from synthetic test feedback and does not infer approval from connectivity or empty comments.
